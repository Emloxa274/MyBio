/capabilities

Three domains, one approach: go deep, then rebuild.

Game Dev & Reverse Engineering

In games, I'm not just a player — I'm the one setting the rules.

  • System manipulation: intervening in memory management, process monitoring, and entity-rendering behavior to alter in-game mechanics.
  • Engine integration: matchmaking systems, intricate UI/UX logic, in-game economies, and probability-driven crafting algorithms.
  • Custom mod APIs: writing bespoke layers on top of existing game infrastructure, restructuring everything from inventory limits to interfaces.

Desktop & System Software

Deep command of Windows internals lets me ship standalone, high-performance software.

  • Native Windows multimedia libraries powering dark-mode, professional audio-visual studio applications.
  • Custom licensing modules and security tools that track system processes.
  • Python (CustomTkinter) network utilities that monitor local traffic and intervene in ARP cache behavior.

Web & AI Automation

Modern web technology, used to build tools that push past their intended limits.

  • Browser extensions: bypassing content security policies, converting a cropped screen region to text via OCR.
  • Automation & scraping: DOM button injectors and custom API payloads routing web media straight into the browser's download manager.
  • AI panels: memory-backed, responsive interfaces where multiple AI agents work in parallel to automate tasks like code segmentation and document editing.
